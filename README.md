# Portfolio

Personal site of Sanjoy Kumar Basu (Biomedical Sciences and Technology, IIT Guwahati), served by GitHub Pages at
https://sanjoybasuiitg.github.io/Portfolio/

- `index.html` Home, `journey.html` Journey, `publications.html` Publications, `fun.html` Fun Pictures
- `motion.css`, `motion.js` all motion, shared by every page
- Plain HTML, CSS and vanilla JS with the Tailwind CDN; no build step
